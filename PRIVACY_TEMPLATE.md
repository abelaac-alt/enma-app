# Plantilla de política de privacidad para Enma

> Plantilla técnica. Debe adaptarse y revisarse jurídicamente antes de publicar la aplicación.

Enma trata datos de cuenta y datos de seguimiento menstrual introducidos voluntariamente por la usuaria. Estos datos se utilizan para mostrar el historial, calcular estimaciones de próximas fechas y, únicamente cuando la usuaria lo autoriza mediante emparejamiento, permitir a su pareja vinculada consultar el ciclo en modo de solo lectura.

Los datos se almacenan en la infraestructura de Supabase configurada por el responsable de Enma. La aplicación aplica controles de acceso a nivel de base de datos para limitar el acceso a la persona titular de la cuenta y, cuando corresponda, a la pareja expresamente vinculada.

Las predicciones ofrecidas por Enma son orientativas y no deben utilizarse como diagnóstico médico, como método anticonceptivo ni para sustituir el consejo de un profesional sanitario.

Antes de publicar, completar al menos: identidad y contacto del responsable, base jurídica, finalidades, plazos de conservación, encargados/subencargados, transferencias internacionales, derechos RGPD, procedimiento de supresión, contacto de privacidad y fecha de última actualización.
